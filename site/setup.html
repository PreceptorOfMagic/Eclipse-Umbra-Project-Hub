Installation Guide

Client on the screen. Host on the gaming PC.

Install Eclipse where you want to play and Umbra on every Windows PC you want to stream. The same pairing supports normal one-host sessions and the optional two-host co-op mode.

  • Eclipse · Windows x64

  • Umbra · Windows x64

2 · Install the host

Put Umbra on each Windows gaming PC.

One Umbra host is enough for standard streaming. Install the same compatible Umbra release on two PCs for co-op. The installer contains the supporting components needed by that build; do not install those pieces separately.

Umbra for Windows x64

Run the signed or checksummed installer from the Umbra release, allow the requested firewall access, then open its local web interface to finish setup.

Umbra downloads

3 · Pair and stream

Your first session is an ordinary one-host stream.

Getting one host working first confirms the network, decoder, encoder, firewall and input path before adding co-op.

  1. 01

    Open Eclipse and add the host

    Keep the client and gaming PC on the same trusted network. Select the discovered Umbra PC or add its address, then begin pairing.

  2. 02

    Enter the pairing PIN in Umbra

    Open Umbra's local web interface on the gaming PC, approve the PIN, then return to Eclipse.

  3. 03

    Launch a game or the desktop

    Choose the application in Eclipse. Umbra prepares the display and encoder automatically; Eclipse negotiates the supported codec, resolution, frame rate, audio and controls.

  4. 04

    Tune only what you need

    The defaults target a working session. Use Eclipse settings when you want a different resolution, frame rate, bitrate, codec, HDR mode, audio layout or input behaviour.

4 · Add couch co-op

Pair a second host; Eclipse handles the co-op defaults.

Co-op should not require copying addresses into a settings pane or manually matching encoder parameters. The first co-op launch creates the working configuration, and the dedicated co-op options appear automatically after co-op has been used.

  1. 01

    Install Umbra on the second PC

    Use a host release compatible with the Eclipse client, pair it in the same way as the first PC, and confirm that it can stream normally on its own.

  2. 02

    Choose Co-op in Eclipse

    Select two paired hosts, choose side-by-side or stacked, decide which host is Player 1, and assign each connected controller or supported keyboard/mouse input.

  3. 03

    Start both sessions

    Eclipse and Umbra negotiate the compatible co-op encoder path automatically—including the mixed-vendor path when the hosts use different supported GPU vendors.

  4. 04

    Adjust later if desired

    After the first co-op session, Eclipse exposes the separate co-op settings automatically. Their installed defaults are intended to work without manual preparation.

Game requirements still apply.

Each PC runs its own copy or session of the game. Accounts, licences, online multiplayer, anti-cheat rules and save data remain the responsibility of the game and its platform.

If something fails

Share the diagnostic bundle with the exact setup.

The logs are designed to make remote hardware reports useful.

In Eclipse

Open the Share/diagnostics area, refresh the bundle after reproducing the problem, and save it. The bundle records the client build, OS, CPU, memory, GPU and driver, display and media capabilities, controllers, network, host facts, settings, session events and performance totals.

In GitHub

Open an issue in the component that showed the problem. State whether a normal stream works, identify both hosts for co-op, list the steps and visible result, and attach the reviewed diagnostic bundle. Remove any addresses, account names or other personal details you do not want to publish.
