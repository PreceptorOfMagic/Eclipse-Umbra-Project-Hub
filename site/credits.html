Direct lineage

The projects this work extends.

Release honesty

A thank-you page is not a licence bundle.

The client repository carries an explicit Aurora/Moonlight TV derivative copyright declaration. A prior verification IPK confirmed only the project licence, copyright declaration and acknowledgements at their expected package paths; it did not establish a complete artifact-specific third-party notice bundle, and it was not deployed or approved for release. The source packaging rules now also stage exact embedded Montserrat, Font Awesome, Unscii and Reed–Solomon records, but no newly generated package has yet been inspected against those rules. Remaining client work includes copied-snippet and libCEC-derived-file closure, Material Icons, inherited artwork on unvalidated platforms, translations and extra mappings, plus the final SBOM and immutable corresponding-source reference. Targeted Umbra notices and source-manifest handling have been drafted locally, but the current default branch does not yet contain that packaging work and no generated host artifact has verified it. Its full static-link closure, copied-source provenance and especially the SudoVDA/Microsoft/VirtualDrivers chain remain open. The CTM installer also still needs its artifact-specific inventory, notices and source offer. Those items remain launch gates.

Current fork integration and testing are maintained by @PreceptorOfMagic with everyone who reports, tests, reviews and contributes. If an attribution is incomplete, please open an issue with a primary source and the affected release.
