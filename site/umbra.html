The host application

Umbra

A self-hosted Windows game-streaming server derived from Sunshine and Apollo. Use it with Eclipse for ordinary one-PC streaming, or install it on two gaming PCs for coordinated couch co-op.

Self-hosted streaming

The normal host experience remains intact.

Umbra is not a co-op-only service. It keeps Apollo's browser configuration, pairing, application management, virtual display and granular device controls while adding the host-side work needed by Eclipse.

Pair and launch

Approve Eclipse with a PIN, manage applications through the local web interface, and give each paired client only the viewing, launch, input, clipboard and command permissions it needs.

Virtual display

Create an on-demand Windows display at the client's chosen size and refresh rate, apply per-device overrides, follow supported HDR requests and clean up the display with the application or session lifecycle.

Encoder choice

Probe NVIDIA NVENC, AMD AMF, Intel Quick Sync and software paths at runtime. Codec, HDR, size and frame rate still depend on the GPU, driver, Windows version and receiving client.

Session tools

Low-delay stereo, 5.1 or 7.1 audio, input-only access, clipboard synchronisation, connection hooks, host logs and resumable sessions support the normal remote-gaming workflow.

The reason for Umbra

Cross-vendor co-op needs a host that understands the client.

Joining two live bitstreams is stricter than displaying them separately. GPU encoders can produce incompatible structures, especially across vendors. Umbra exposes the capabilities and custom co-op encoder behaviour Eclipse needs so both panes can be negotiated as one reliable output.

That coordinated contract is why Eclipse and Umbra are released as one project, while remaining separate client and host repositories.

Install once per gaming PC

Everything required by the Umbra build ships through its installer.

Do not assemble supporting components by hand. Install Umbra, approve the firewall prompt, pair Eclipse and let the applications negotiate a standard or co-op session.
